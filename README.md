# 🌍 지구 공전·자기권·달·혜성·태양풍 & 가상 지진운 물리 시뮬레이터
### (Earth Orbit, Magnetosphere, Moon, Comet, Solar Wind & Virtual Earthquake Cloud Simulation)

본 프로젝트는 지구 쌍극자 자기장, 달의 공전과 조석, 태양풍·행성간 자기장(IMF), 외부 자기원, 구름 입자 및 지각 응력 사이의 **가설적 결합**을 2D/3D로 탐색하는 연구용 시뮬레이터입니다.

> [!IMPORTANT]
> 이 프로그램은 지진 예측의 유효성이 입증된 도구가 아닙니다. 지진운·외부 자기장·지각 응력의 인과 연결은 연구 가설이며, 화면의 결과는 관측 사실이나 재난 경보가 아니라 설정된 방정식과 계수에서 나온 시뮬레이션 값입니다. 실제 안전 판단에는 공식 기상·지진 기관의 정보를 사용하십시오.

확립된 물리식은 기준선과 대조군으로, 아직 확인되지 않은 결합은 조정 가능한 가설 계수로 구분하는 방향으로 개발합니다. 이 구분은 가설을 배제하기 위한 것이 아니라 반증 가능하고 재현 가능한 형태로 시험하기 위한 것입니다.

식의 단위, 근거, 가설/대조군 계약은 [`PHYSICS_MODEL.md`](PHYSICS_MODEL.md)에 정리되어 있습니다.

## 현재 모델과 조작법 (계산 계약 v2)

- **공통 자기장**: 2D/3D가 동일한 벡터식을 사용합니다. 2D는 z=0 단면입니다. 3D 임의 변형을 제거하고 합성장을 RK4로 적분합니다. 정자기 중첩 근사이며 완전한 MHD, 재결합, 차폐 전류를 풀지 않습니다.
- **감쇠와 거리**: 쌍극자 원거리장은 r⁻³. 밝기는 0.01 → 1 → 100 → 31,200 nT 고정 로그 눈금입니다. 1 R_E=6,371 km. 지구 탭에서 중심 거리 눈금을 켜고 우클릭으로 거리를 읽습니다. 3D 우클릭은 z=0 단면 교점입니다. 표시 펄스는 에너지 수송 해가 아닙니다.
- **두 경계**: 보라색 점선은 지구 성분의 지정 nT 등치선(기본 10 nT), 주황색은 태양풍 전용 Shue 자기권계면입니다. 전자는 0 경계가 아니며 후자는 임의 외부 자기원에 대한 응답을 포함하지 않습니다. Shue 적용 보호 범위 밖에서는 경고하고 경계 표시를 중단합니다.
- **외부장 입력**: 외부 자극에서 종류 선택 → nT 입력 → nT 적용 → 자기원 추가. 1e1000 등 과학적 표기와 ∞를 지원하며 임의의 nT 상한은 없습니다. 쌍극자 기준은 자기원 중심에서 1 R_E 적도의 이상적 세기입니다. 지구 도달 세기는 별도 수치 상자에서 확인합니다. ∞는 방향 극한이며 무한 에너지의 실제 예측이 아닙니다. 초대형 값에서는 일반 구름·파열·Python 정량 계산을 중단하고 입력을 유지합니다. 좌표·회전·혜성 활동도의 수치 보호 범위와 구분합니다.
- **극성과 운동**: 기본은 N/S 한 쌍 쌍극자 또는 균일장. 독립 N/S 단극자는 반드시 가설 목록에서만 추가합니다. 자체 회전은 축 각도, 공전은 위치를 바꿉니다. 부호 있는 °/화면 초로 회전 방향·속도를 정하고 일시정지는 양쪽 뷰에서 공유합니다. 지정 운동이지 토크를 푼 강체 운동은 아닙니다.
- **달**: 기본 물리/표시 거리 모두 60.3 R_E, 공전주기 27.3일. 1초당 진행 일수를 조절하고 달 궤도 맞춤을 사용합니다. 강한 달 전역 쌍극자와 인공 후류는 기본 계산에서 제거했습니다. 달 전역 쌍극자는 별도 가설 토글이며 국소 지각장/해양 조석 전류의 정밀 재현이 아닙니다. 조석 응력은 가역적 합성 섭동입니다.
- **지구의 자전·태양 공전 연동**: 상단 **태양 공전** 화면에서 태양 중심 공전, 2D 벡터장, 3D 자기권을 동시에 표시합니다. 세 패널은 동일한 시간·자기장·외부 자극·레이어 상태를 공유합니다. 케플러 궤도(a=1 AU, e=0.0167, T=365.256일)와 항성 자전(23.934 h)을 같은 물리 시간으로 진행하며, 태양풍 진행 방향, 자전축 23.44°와 지자기축 오프셋의 평면 투영, 정상상태 방사형 흐름을 가정한 동압 `(1 AU/r)²` 보정을 2D·3D에 공통 적용합니다. 실제 순간 태양풍 속도·IMF·CME는 공전만으로 예측하지 않고 기존 입력을 유지합니다. 태양풍 OFF도 그대로 존중하며, 이 연동은 완전한 3D MHD가 아닙니다.
- **외핵**: 지구 탭에서 문헌 기반 유속 규모와 기본 15 km/년 설명도를 확인합니다. Δu=κT²P_extτ/(ρL)은 **반드시 가설**, 기본 OFF/전달률 0. 감속·가속 민감도를 비교하지만 관측 임계값이나 완전한 다이너모 해가 아니고 지구 모멘트에 자동 피드백하지 않습니다.
- **구름 고도**: 기본 12±1.5 km 지정 층에 공유 입자/띠를 배치합니다. 지진운 탭의 고도 ×1/×30/×100은 표시만 확대합니다. 3D도 동일한 z=0 단면이며 독립 3D 유체 해가 아닙니다. 대류권계면은 위도·계절에 따라 변하고 중층 고적운과 고층 권적운은 다른 분류입니다.
- **구름 가설**: 기상 기준선 위에 선택적 방향/주기 결합을 더합니다. cos 위상·파장을 부여한 무늬는 자발적 형성의 증거가 아닙니다. A_h=0 또는 가설 OFF로 대조합니다. 방향 정렬·공간 집적·핵생성·응결은 다른 과정입니다. 지상 하늘은 물리 고도층의 단순 투영, 격리/3분할은 실제 구름 배치가 아닌 스칼라 함수 진단 지도입니다.
- **CERN CLOUD**: 경계층 SA–NH3/DMA, 해양·극지 HIOx/MSA, 상부대류권 IP-OOM 스크리닝을 보존합니다. J*, GR*, κ-Köhler CCN 점수는 전체 논문 적합식이나 실제 구름량이 아닙니다. 이온 채널 J_ion≤q, 기상 기준선 연결은 별도 가설 옵션입니다.
- **기상·파열**: Open-Meteo/NOAA 수신 상태와 프리셋을 구분합니다. 단층 노드, P/S 파면, 가정한 응력강하/반경의 Mw는 합성 결과이며 지진 예측이 아닙니다.

## 자기축 움직임과 시간 배율 해석 — 오해 방지

> [!CAUTION]
> 태양 공전 화면에서 자기축이 빠르게 좌우로 흔들려 보이는 것은 지구의 고유 자기축이 실제로 그렇게 진동한다는 뜻이 아닙니다. 지구와 함께 회전하는 지자기축을 태양–지구 방향의 2D 단면에 투영한 값이 빠른 화면 시간에서 반복되는 표현입니다.

실제 지자기축은 자전축에서 약 11° 기울어진 채 지구와 함께 회전합니다. 지구 고정 좌표에서는 자기축이 하루마다 좌우로 왕복하지 않지만, 태양풍 좌표에서 본 자기축의 상대 방향은 일주·계절 주기로 달라질 수 있습니다. 자기극의 장기적인 이동과 지구 자기장 세기의 영년 변화는 이 자전 애니메이션과 다른 현상이며 현재 공전 모델에서 계산하지 않습니다.

현재 앱은 완전한 3D 지자기 좌표 변환이나 MHD를 풀지 않고 다음 평면 투영 프록시를 사용합니다.

`화면 쌍극 투영각 = 23.44° + (사용자 지자기축 오프셋) × cos(자전 위상)`

기본 지자기축 오프셋 `11.5°`에서는 화면 투영각이 약 `11.94°–34.94°` 사이를 왕복합니다. 이는 자기장의 고유 세기가 같은 범위로 증감하거나 자기축이 물리적으로 흔들린다는 의미가 아닙니다. 2D와 3D가 같은 단면 프록시를 공유하기 때문에 두 화면의 자기력선 방향도 함께 바뀝니다. 실제 3D에서는 지자기축이 자전축 주위를 원뿔 형태로 회전한다고 해석해야 합니다.

기본 시간 배율은 `실제 5일 / 화면 1초`입니다.

| 구분 | 기본 화면 표현 | 물리적 의미 |
|---|---:|---|
| 시간 가속 | `5 × 86,400 = 432,000배` | 물리 과정의 진행 시간만 압축 |
| 지구 공전 1회 | `365.256 / 5 ≈ 73.0512초` | 실제 항성 공전주기 365.256일 |
| 지구 자전 1회 | `(23.9344696 / 24) / 5 ≈ 0.19945초` | 실제 항성 자전주기 약 23.934시간 |
| 화면 1초당 자전 | 약 `5.01회` | 빠른 자기축 투영 반복의 원인 |
| 표시 공전 속도 | 약 `29.3–30.3 km/s` | 시간 배율을 곱하지 않은 실제 궤도상의 순간 속도 |

따라서 화면의 지구는 실제보다 `432,000배` 빠르게 궤도 위상을 진행하지만, 화면에 표시되는 `km/s`, `AU`, `nPa`, `nT` 값 자체를 432,000배로 증폭하지 않습니다. 자기축 움직임을 천천히 확인하려면 태양 공전 탭의 **시간 배율(실제 일/화면 초)**을 낮추십시오. 태양풍 순간 변동, IMF 방향 변화, CME와 지구 자기장 내부의 장기 변화는 공전 시간 가속만으로 생성하지 않습니다.

## 화면과 성능

- 상단의 2D/3D/분할/태양 공전 선택, 휠 확대/축소, 3D 드래그 카메라 회전을 지원합니다. 태양 공전의 시간 상태는 달·외부 자극과 같은 전체 재생/정지를 공유하며 2D/3D/분할 화면 하단에도 현재 AU와 속도가 표시됩니다.
- 2D의 **달 궤도 맞춤**은 **표준** 왼쪽 도구 버튼입니다. 화면 시각 요소 가이드는 도구 줄 아래에 배치되어 분할 뷰의 줄바꿈에도 겹치지 않습니다.
- **3D 표시 패널**: 접기/펼치기, 검색, 개별 토글, 전체 켜기/숨김, 표시 초기화. 3D 지원 11개 레이어만 나오며 분할 화면 공통 항목과 즉시 동기화합니다. 2D 전용 6개 항목은 3D 전체 숨김으로 바꾸지 않습니다.
- 자기장 수치·범례·모델 한계를 펼쳐 nT/달/외핵/계산 시간을 확인합니다.
- 전체 화면은 시뮬레이션만 확대하며 분할도 지원합니다. 종료 버튼 또는 Esc로 복귀합니다.
- 용어·이론 해설에서 용어·단위·이론·논문을 검색하고 **반드시 가설** 항목만 필터링합니다.
- RK4는 Web Worker에서 뷰별 최대 4 Hz 계산하며 진행 중 1개/최신 입력 1개로 대기열을 제한합니다. 달 기본 공전은 자기장 작업을 다시 실행하지 않습니다.
- 2D는 최대 30 FPS, 격자 진단은 최대 4 Hz와 샘플 예산을 사용합니다. 3D는 렌더러/버퍼를 재사용하고 픽셀 비율을 제한합니다. 이는 자기장 세기 제한이 아니며 모든 장치·해상도·자기원 수에서 일정 FPS를 보장하지 않습니다.
- Python 내보내기는 창을 연 시점의 입력과 schemaVersion=2를 고정합니다. 자기장 식은 공통 엔진과 비교하며, 구름 그래프는 시간 0의 진단 예시이지 확률 입자 궤적/기상 텍스처의 완전 재현은 아닙니다.

## SNS 공유 미리보기

SNS 공유 이미지는 실제 시뮬레이션의 전체 화면·2D/3D 분할 뷰를 캡처한 1200×630 JPEG입니다. `public/assets/og-split-fullscreen-20260904.jpg`를 `index.html`의 Open Graph 및 Twitter 카드 메타데이터에서 참조합니다. 이미지 교체 시 파일명과 양쪽 이미지 URL·치수·대체 설명을 함께 갱신해야 합니다. 공유 이미지는 정적인 캡처이며 사용자의 현재 시뮬레이션 상태를 실시간으로 반영하지 않습니다.

메타데이터 형식: [Open Graph protocol](https://ogp.me/).

## 검증 범위 (2026-09-07)

- 타입 검사: `npm run lint` 통과.
- 자동 테스트: 41개 통과. 지구 공전의 케플러 잔차·근일점/원일점·공전/항성 자전 공용 시계·거리 역제곱 동압·태양풍/경계 방향 회전을 포함해 거리 감쇠, 2D/3D 공통 장, 회전/달 대조군, 초대형·무한 입력, 구름 고도, Python 내보내기 수치 일치, API 입력 검증 및 SNS 이미지 메타데이터를 검사합니다.
- 빌드: `npm run build`로 프런트엔드와 로컬 API 서버 빌드 통과. 500 kB 초과 번들 경고가 남아 있어 첫 로딩 시간은 네트워크·장치에 따라 달라집니다.
- 브라우저 확인: 3D 패널 접기/펼치기와 전체 숨김/켜기, 분할 화면 연동, 외부 쌍극자 회전, 지상→우주 복귀, `1e1000`/`∞` 경고, 해설 검색·가설 필터.
- 확인 한계: 모든 GPU·해상도·브라우저의 성능, 실제 모니터 전체 화면 유지, 유료 Gemini 실제 호출은 검증 범위에 포함하지 않습니다. 테스트 통과는 물리적 가설 입증이 아닙니다.

브라우저의 **Web Worker**는 자기력선 계산용이며, 별도 서버인 **Cloudflare Worker**(선택적 Gemini API 프록시)와 다릅니다. GitHub Pages 프런트엔드 배포만으로 Cloudflare Worker가 갱신되지는 않습니다.

## 🔐 GitHub Pages와 Gemini API

계산 계약 v2의 균일장·문자열 nT를 AI에 전달하려면 Worker도 최신 코드로 다시 배포해야 합니다. 이번 작업에서 API 키·권한·CORS 설정은 변경하지 않았습니다.

GitHub Pages는 정적 파일만 제공하므로 Gemini 비밀키를 안전하게 보관하거나 `/api` 요청을 직접 처리할 수 없습니다. 이 저장소의 `worker/`는 다음 역할을 하는 선택적 Cloudflare Worker 프록시입니다.

- 허용된 웹 주소만 받는 CORS 검사
- 요청 크기·형식·값 범위 검증
- 계정별 Rate Limiting과 선택적 Turnstile 검증
- Cloudflare Secret에 저장된 `GEMINI_API_KEY`로만 Gemini 호출
- 내부 오류·프롬프트·비밀키를 브라우저 로그에 노출하지 않음

설정 절차와 배포 명령은 [`worker/README.md`](worker/README.md)를 참고하십시오. Worker 배포 후 GitHub Pages 빌드 환경의 `VITE_API_BASE_URL`에 Worker 주소를 지정해야 AI 기능이 활성화됩니다. Worker를 배포하지 않아도 로컬 시뮬레이션 자체는 사용할 수 있습니다.
