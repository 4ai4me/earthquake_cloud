# 🌍 지구 자기권·달·혜성·태양풍 & 가상 지진운 물리 시뮬레이터
### (Earth Magnetosphere, Moon, Comet, Solar Wind & Virtual Earthquake Cloud Simulation)

본 프로젝트는 지구 쌍극자 자기장, 달의 공전과 조석, 태양풍·행성간 자기장(IMF), 외부 자기원, 구름 입자 및 지각 응력 사이의 **가설적 결합**을 2D/3D로 탐색하는 연구용 시뮬레이터입니다.

> [!IMPORTANT]
> 이 프로그램은 지진 예측의 유효성이 입증된 도구가 아닙니다. 지진운·외부 자기장·지각 응력의 인과 연결은 연구 가설이며, 화면의 결과는 관측 사실이나 재난 경보가 아니라 설정된 방정식과 계수에서 나온 시뮬레이션 값입니다. 실제 안전 판단에는 공식 기상·지진 기관의 정보를 사용하십시오.

확립된 물리식은 기준선과 대조군으로, 아직 확인되지 않은 결합은 조정 가능한 가설 계수로 구분하는 방향으로 개발합니다. 이 구분은 가설을 배제하기 위한 것이 아니라 반증 가능하고 재현 가능한 형태로 시험하기 위한 것입니다.

식의 단위, 근거, 가설/대조군 계약은 [`PHYSICS_MODEL.md`](PHYSICS_MODEL.md)에 정리되어 있습니다.

## 🌟 주요 기능 및 물리 모델 (Core Physics & Features)

### 1. 🌐 지구 쌍극자 자기장 (Earth Dipole) & 지자기 역전
- **쌍극자 모멘트 $\mathbf{m}$**: 지오다이내모에 의한 자기장 세기 ($0.2 \sim 6.0\text{ M}_E$, 기본값 $1.0\text{ M}_E$)
- **자축 경사각 $\theta$**: 실제 지자기축 경사각 ($11.5^\circ$) 및 임의 각도 틸트
- **지자기 역전 (Geomagnetic Flip)**: 마투야마-브륀스 지자기 N/S 극성 반전 시뮬레이션
- **지구 기본값 복원**: 클릭 한 번으로 표준 지구 환경($1.0\text{ M}_E, 11.5^\circ$, 정상 극성)으로 원복

### 2. 🌕 지구 위성 "달(Moon)" 천체 물리 연동
- **공전 궤도 및 위상각**: 실제 평균 중심 거리 약 $60.3\text{ R}_E$ ($384,400\text{ km}$)와 화면용 3.5 world-unit 표시 궤도를 분리
- **부드러운 자동 공전**: 달 위치·달 자기장·기조력은 매 렌더 프레임의 최신 위상으로 계산하고, React 제어 패널의 위상 표시는 초당 4회만 동기화하여 전체 UI 재렌더로 인한 끊김을 방지
- **고체 지구 조석력(Solid Earth Tidal Stress)**:
  $$\Delta \sigma_{\text{tide}}(\theta, d) = \frac{3 G M_M R_E^2}{2 d^3} \left( 3\cos^2\theta - 1 \right)$$
  달의 중력 구배에 의한 가역적 지각 응력 변조와 삭망월(신월·보름) 민감도 비교. 조석은 판구조 응력으로 누적되거나 지진 원인으로 단정되지 않습니다.
- **달 고유 잔류자기장 & 태양풍 플라즈마 후류(Plasma Wake)**: 달 지각 암석의 잔류 자화 벡터 및 반대편 플라즈마 차폐 공동 렌더링
- **달 마우스 드래그 조작**: 캔버스에서 달을 직접 클릭하여 직관적으로 공전 궤도 및 위치 변경

### 3. ☄️ 접근 혜성 (Comet Approach) 물리 모델
- **코마 가스 승화 및 광전리 (Photoionization)**: 태양열로 방출된 가스가 이온화되어 태양풍 자기장에 질량 부하(Mass-loading) 발생
- **반자성 공동 (Diamagnetic Cavity)**: 혜성 핵 부근의 무자기장 영역 형성
- **이온 꼬리(Ion Tail) & 먼지 꼬리(Dust Tail)**: 태양 반대 방향($+x$)으로 뻗어나가는 이온 플라즈마 꼬리 및 곡선형 먼지 꼬리
- **직교 파동 간섭 가설**: 혜성 플라즈마와 지구 자기권의 합성 간섭을 국소 대기 파동운 항으로 연결하는 사용자 가설 시나리오

### 4. ☀️ 태양풍(Solar Wind) & 행성간 자기장(IMF)
- **동압축 ($P_{dyn} = \rho v^2$)**: 초음속 플라즈마에 의한 주간측 자기권계면 압축 및 자기권 꼬리 신장
- **IMF $B_z$ (남북 성분)**: 남향($B_z < 0$) 유입 시 자기력선 재결합(Magnetic Reconnection) 및 X점(Neutral Point) 형성
- **태양 플레어 CME 폭풍 트리거**: 코로나 질량 방출 펄스 유입으로 극대화된 지자기 교란 시뮬레이션

### 5. ☁️ 가상 지진운 (Atmospheric Wave Clouds) & 양떼구름 모델
- **무차원 자기 섭동 지표 $I(x,y)$**:
  $$s=\frac{|\mathbf B_E\times\mathbf B_X|}{|\mathbf B_E||\mathbf B_X|},\quad q=\frac{|\mathbf B_X|}{|\mathbf B_E|+|\mathbf B_X|},\quad I=q[(1-\alpha)s+\alpha\tanh(L|\nabla B|/B)]$$
- **시그모이드 국소 마스크 $M(x,y)$**:
  $$M(x,y) = \frac{1}{1 + e^{-k(I(x,y) - I_{\text{th}})}}$$
- **가설 결합 파동운 기여 $C_h(x,y)$**:
  $$C_h(x,y) = A_h M(x,y) \left[ \frac{1 + \cos\left(\mathbf{k}_\perp\cdot\mathbf r-\omega t\right)}{2} \right],\qquad A_h=0\;\text{(대조군)}$$
- **입자 기준선**: 바람 이류, Stokes 항력, 난류 확산을 먼저 계산하고 자기장 관련 병진력은 $\nabla B^2$ 방향의 magnetophoresis 형태로 제한합니다. 가설적 밴드 이동은 별도 $A_h$ 항으로 표시합니다.
- **외부 자극원 조건부 게이팅**: 무차원 간섭 지표가 사용자가 정한 `간섭 임계값`을 넘을 때 가설적 파동운 항이 활성화됩니다. 기본 임계값은 0.30이며 변경 가능합니다. 평상시에는 수원 관측소 등 **기상 기반 구름 기준선**을 사용합니다.

### 6. 🧪 CERN CLOUD 에어로졸 기준선 실험
- **독립 실험 모드**: 경계층 `H₂SO₄–NH₃/DMA`, 저온 해양·극지 `HIOx/MSA`, 상부대류권 `IP-OOM` 프리셋을 제공합니다.
- **단계별 계산**: 응축손실 생존율 → 중성·이온 유도 핵생성 `J*` → 성장률 `GR*` → 최종 건조직경 → κ-Köhler 임계직경과 CCN 활성 가능성을 계산합니다.
- **입력 단위**: 온도 K, 압력 hPa, 상대습도 %, 이온쌍 생성률 cm⁻³ s⁻¹, 증기 농도 cm⁻³, NH₃/DMA pptv, 응축손실 s⁻¹, 성장시간 h, 과포화도 %를 사용합니다.
- **적용 범위 경고**: 선택한 화학 채널의 실험 온도·습도·이온 범위를 벗어나면 화면에 경고합니다.
- **선택적 기준선 연결**: `기상 구름 기준선에 CCN 민감도 연결`을 켜면 기존 자연 구름 프록시만 70–100% 범위에서 조정합니다. 자기장 가설항 $A_h$와는 항상 분리됩니다.

> [!NOTE]
> 이 계산은 공개 논문에서 보고된 의존성과 대표 범위를 사용한 **스크리닝 모델**입니다. 표시되는 `J*`, `GR*`, `CCN 활성 가능성`은 CERN의 측정값, 완전한 다차원 적합식, 실제 CCN 농도 또는 구름 예보가 아닙니다.

### 7. 🌐 세계 기상·우주환경 데이터 연동 (Open-Meteo / NOAA SWPC)
- **대한민국 수원 관측소**: 위도 북위 약 37.26° (37° 15′ N), 경도 동경 약 127.02° (127° 01′ E) 정밀 좌표 추가
- Open-Meteo의 지상 기상과 NOAA SWPC의 Kp·태양풍 플라즈마·IMF 데이터를 각각 조회
- 일부 출처만 성공한 경우 `부분 실시간`, 모두 실패한 경우 오류로 명시하며 누락값을 Kp에서 임의 생성하지 않음
- 현재 Dst는 실시간 출처에 연결하지 않고 시뮬레이션 기준값으로 표시

### 8. ⚡ 지각 응력(Crustal Stress) & 지진 파열(Rupture)
- 48개 합성 단층 노드의 판구조 하중 누적과 가역적 달 조석·자기 가설 섭동 분리
- 파열 시 원형 균열의 $M_0=(16/7)\Delta\sigma a^3$와 $M_w=(2/3)[\log_{10}(M_0)-9.1]$을 사용하되, 반경·응력강하가 가정값이므로 출력 규모는 합성 시나리오로 표시

## 🎮 시뮬레이터 사용법 (User Manual)

### 1. 기본 뷰포트 인터랙션
- **화면 이동 (Pan)**: 캔버스의 빈 공간을 마우스 좌클릭한 채 드래그합니다.
- **확대 / 축소 (Zoom)**: 마우스 휠을 스크롤합니다. *(외부 웹페이지 스크롤과 엄격히 분리되어 페이지가 튀지 않습니다)*
- **천체 및 자극원 이동**:
  - **지구**: 지구 본체를 클릭 & 드래그하여 중심 위치를 이동합니다.
  - **달**: 달 천체를 클릭 & 드래그하여 궤도 반경과 위상각을 직접 조절합니다.
  - **외부 자극원 / 혜성**: 자극원 노드를 마우스로 드래그하여 원하는 위치로 배치합니다.
- **마우스 우클릭 (벡터 프로브)**:
  - 캔버스의 임의 좌표를 **마우스 우클릭**하면 해당 위치의 자기장 벡터($B_x, B_y, |\mathbf{B}|$), 자기 구배($\|\nabla B\|$), 간섭 강도($I$), 지진운 밀도, 인근 단층 응력 수치가 팝업으로 정밀 분석됩니다.

### 2. 상단 툴바 및 뷰 모드
- **2D 시뮬레이션 뷰**: 실시간 2D 평면 자기력선, 히트맵, 대기 입자, 지진운 파동 렌더링. RK4 추적 범위·간격·시드 껍질은 현재 줌과 가시 영역에 맞춰 조절되어 줌 아웃 시에도 외곽 자기력선과 에너지 펄스를 표시합니다.
- **3D 공간 자기권 뷰**: 3차원 지구 자기권계면(Magnetopause), 밴앨런 방사선대, 3D 자기력선 궤적 렌더링. 활성 외부 자기원은 종류·극성·세기에 따라 제한된 3D 변형과 위치 마커로 표현됩니다. 이 변형은 가설 탐색용 시각 결합이며 검증된 MHD 예측값이 아닙니다.
- **2D/3D 동시 분할 뷰**: 좌우 분할 화면으로 2D 정밀 수치와 3D 입체 기하를 실시간 비교
- **히트맵 컬러맵 전환**: 자기장 세기($|\mathbf{B}|$), 자기 구배($\|\nabla B\|$), 지진운 간섭 강도($I$) 중 선택
- **레이어 토글**: 자기력선, 자기장 히트맵, 대기 입자, 지진운 밴드, 달 궤도, 기조력 타원체, 외부 자극원 표시 여부와 전체 켜기/숨기기를 즉시 On/Off

### 3. 우측 컨트롤 덱 (Physics Controls)
1. **시나리오 프리셋 (Presets)**:
   - `표준 평온 지구`: 기본 상태
   - `태양풍 CME 폭풍`: 강력한 태양풍과 남향 IMF
   - `외부 혜성 접근`: 혜성 코마와 이온 꼬리 간섭
   - `삭망월 조석력 극대화`: 보름달 위상과 최대 기조력 응력
   - `제3의 우주 자기원`: 비대칭 자기력선 왜곡
   - `가상 지진운 & 지각 파열`: 임계 지진운과 단층 파쇄
   - **전체 초기화 (Master Reset)**: 모든 외부 자극을 제거하고 기본 환경으로 원복
2. **지구 쌍극자 (Earth)**: 자기 모멘트, 자축 경사각, 극성 반전 및 `지구 기본값 복원` 버튼
3. **달 위성 (Moon)**: 위상각, 궤도 거리, 조석력 가중치, 잔류자기장, 자동 공전 토글 및 `달 기본값 복원` 버튼
4. **외부 자극원 & 혜성 (Sources)**: N극, S극, 쌍극자, **혜성(Comet)** 추가 및 관리, `전체 제거` 버튼
5. **태양풍 & IMF (Solar)**: 동압 $P_{dyn}$, 남북 성분 $B_z$, CME 플레어 유입 버튼 및 `태양풍 기본값 복원` 버튼
6. **가상 지진운 (Cloud)**: 에어로졸 수, 편광 감수율, 양떼구름 파장, 감마 대비, 컬러맵, 관측 시점(우주 전역 / 지상 어안렌즈), 격리 검증 모드(순수 구름, 핫스팟 마스크, 벡터 오버레이, 3분할 뷰) 및 `지진운 기본값 복원` 버튼
7. **CLOUD 실험 (CERN CLOUD)**: 환경 프리셋, 증기·이온·응축손실 조건, 핵생성·성장·κ-Köhler CCN 스크리닝과 선택적 기상 기준선 연결
8. **지각 응력 & 지진 (Stress)**: 단층 응력 상태, 강제 파열(Rupture), 응력 방전 및 발생 이력 카탈로그
9. **세계 기상 연동 (Weather)**: 수원 관측소 및 글로벌 주요 도시 실제 기상 데이터 연동

#### CERN CLOUD 모드 빠른 사용법

1. 우측 `CLOUD 실험` 탭을 열고 대상 환경 프리셋을 고릅니다.
2. 온도·습도·증기 농도 등 입력 단위와 적용 범위 경고를 확인합니다.
3. `총 핵생성률 J*`, `성장률 GR*`, `최종/임계 건조직경`을 순서대로 비교합니다.
4. 기본값은 `독립 실행`입니다. 자연 구름 민감도까지 비교할 때만 기준선 연결을 켭니다.
5. 자기장 가설의 효과는 별도로 `가상 지진운` 탭에서 $A_h=0$ 대조군과 비교합니다.

Node.js 20 이상을 권장합니다. 로컬 Gemini 기능을 쓰려면 `.env.example`을 참고해 서버 환경 변수 `GEMINI_API_KEY`를 설정합니다. 키를 `VITE_` 변수나 프런트엔드 코드에 넣으면 브라우저에 노출되므로 금지합니다.

## 🔐 GitHub Pages와 Gemini API

GitHub Pages는 정적 파일만 제공하므로 Gemini 비밀키를 안전하게 보관하거나 `/api` 요청을 직접 처리할 수 없습니다. 이 저장소의 `worker/`는 다음 역할을 하는 선택적 Cloudflare Worker 프록시입니다.

- 허용된 웹 주소만 받는 CORS 검사
- 요청 크기·형식·값 범위 검증
- 계정별 Rate Limiting과 선택적 Turnstile 검증
- Cloudflare Secret에 저장된 `GEMINI_API_KEY`로만 Gemini 호출
- 내부 오류·프롬프트·비밀키를 브라우저 로그에 노출하지 않음

설정 절차와 배포 명령은 [`worker/README.md`](worker/README.md)를 참고하십시오. Worker 배포 후 GitHub Pages 빌드 환경의 `VITE_API_BASE_URL`에 Worker 주소를 지정해야 AI 기능이 활성화됩니다. Worker를 배포하지 않아도 로컬 시뮬레이션 자체는 사용할 수 있습니다.
